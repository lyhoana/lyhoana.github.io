## 📌 Giới thiệu

Đây là project website cá nhân đầu tiên của mình.

Mục tiêu của project là thực hành quy trình xây dựng và triển khai một website thực tế bằng GitHub, từ việc tạo repository, viết HTML/CSS, commit code cho đến deploy bằng GitHub Pages và kết nối custom domain.

## ✨ Tính năng

- Giao diện portfolio cá nhân.
